# Seguridad

## Reporte de vulnerabilidades

No abras un issue público para una vulnerabilidad no corregida. Usa GitHub Security Advisories cuando el repositorio esté disponible o el canal privado definido por el responsable del proyecto.

Incluye:

- Componente y versión afectada.
- Pasos mínimos para reproducir.
- Impacto observado.
- Evidencia sin datos personales ni credenciales reales.
- Mitigación sugerida, si existe.

## Datos que no deben compartirse

- API keys completas.
- `PJUD_API_KEY`.
- `API_KEY_PEPPER`.
- Contraseñas o dumps de producción.
- Claves SSH de OCI.
- Tokens de GitHub o Cloudflare.
- RUT y respuestas judiciales de usuarios reales.
